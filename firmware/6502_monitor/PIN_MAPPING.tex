\section{Notes}
\begin{itemize}
    \item \textbf{Full 2\,KB ROM:} A0--A10 are decoded, covering all 2048 addresses of the \$D800--\$DFFF range without aliasing.
    \item \textbf{GPIO\,0 (MPD / BOOT):} kept HIGH during boot by the Atari pull-up (isolated via TXS0108E).
    \item \textbf{GPIO\,3 (EXTSEL / RX0):} shared with UART\,RX; not usable for serial input at runtime.
    \item All signals pass through \textbf{TXS0108E} bidirectional level shifters (3.3\,V\,$\leftrightarrow$\,5\,V).
\end{itemize}
